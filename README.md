# hello-liniu 🚀

这是一个精美的纯前端 Web 动画与单页项目合集，完全使用纯原生 HTML5、CSS3、Canvas 2D 与 Web Audio API 构建，零外部依赖，即开即用！

## 📂 项目内容包含

1. **한중다리 (韩中桥) - 韩中语言交换社团单页 (`index.html`)**
   - 包含中韩双语对照介绍、社团活动卡片、本月活动日程表格以及入会咨询交互。
2. **🏎️ 超级赛车 3D 极速动画 (`racing.html`)**
   - 经典 Pseudo-3D 道路透视引擎、AI 交通对手超车、主动升降尾翼、氮气粒子加速与纯代码合成引擎轰鸣声效。
3. **🐍 赛博霓虹贪吃蛇动画 (`snake.html`)**
   - 内置 BFS 智能最优路径寻路算法，支持全自动巡航演示与手动游玩、炫酷粒子爆裂特效及 5 款发光皮肤。
4. **⚡ 本地静态服务器 (`serve.ps1`)**
   - 内置基于 PowerShell 的超轻量 HTTP 服务器，免安装任何环境即可一键启动预览（默认端口 8000）。

## 🛠️ 本地运行方式

- **方式一**：在 Windows PowerShell 中直接运行：
  ```powershell
  .\serve.ps1
  ```
  然后在浏览器访问 `http://localhost:8000/`。
- **方式二**：直接在文件管理器中双击任何 `.html` 文件即可在浏览器中预览。
